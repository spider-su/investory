# 2026 certification oracle

This fixture preserves the externally confirmed calculation values from the certified `.60`
Accounting → Ryczalt migration run for January–August 2026.

It is a test/reference artifact. Production code must not read it, and it must not be used as a
runtime reference table. The values primarily preserve migration certification evidence; they are
not generated by `RyczaltCalculator`, `VatCalculator`, or `ZusCalculator`.

The repository does not currently contain the complete independently verified input-fact dataset
needed to execute calculator certification against this oracle. Do not manufacture those inputs
from the calculated output. Until the authoritative inputs are extracted, this file preserves the
expected oracle only and does not claim calculator certification.
