# Simulation support notes

This directory contains supporting notes and local investigations related to retirement simulation.
It is not the canonical simulation contract.

Use [`../domain/retirement-simulation.md`](../domain/retirement-simulation.md) for deterministic
simulation semantics, [`../domain/planning-timeline.md`](../domain/planning-timeline.md) for
Actual/Live/Projected lifecycle rules, and [`../domain/retirement-analysis.md`](../domain/retirement-analysis.md)
for deterministic Analysis semantics.

`expense-profile.md` is supporting design/reference material. Files named `local-profile-*` are
point-in-time investigation evidence and must not be used to infer current behavior without checking
the canonical contracts and current source.
