# Codex repository guidance

The `.codex` directory contains repository-local agent configuration and repeatable UI-regression
skills.

- `config.toml` contains workspace agent defaults. Keep project behavior and architecture rules in
  `AGENTS.md` or canonical `docs/` files.
- `skills/` contains focused browser-test procedures. Each skill must state its scope, data-safety
  rules, evidence requirements, and failure classification.
- `environments/environment.toml` is generated by the Codex environment setup. Do not edit it by
  hand; update the environment source or setup process instead.

Use the smallest matching UI skill. Route smoke checks prove rendering and browser health;
interaction checks prove selected controls; deep regression proves broader CRUD, persistence, and
financial-value behavior. None of these replaces backend, database, or physical-device validation
when those are required by the task.

The repository working rules and documentation source-of-truth order are in [`AGENTS.md`](../AGENTS.md).
